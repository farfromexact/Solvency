# 偿付能力资产配置情景测算

本项目是一个本地 Streamlit 小程序，用于导入月度偿付能力 Excel 底稿，并基于现有底稿口径估算资产配置变化对最低资本和偿付能力充足率的影响。

## 运行

```powershell
python -m streamlit run app.py
```

打开页面后，可以使用当前目录下的 `1000_20251231_20260113v2.xlsx`，也可以上传同结构的月度底稿。

## 当前模块

- 加仓/减仓/建仓：按资产类型或账户做比例/金额调整，系统按选中对象现有结构同比缩放认可价值和各类风险暴露。
- 上涨/下跌：按资产类型或账户做价格涨跌测算，估值变动默认计入实际资本和核心资本，并同步估算最低资本变化。
- 政策参数：支持最低资本乘数、市场风险乘数、信用风险乘数；可用于粗略模拟政策 overlay。

## 当前口径

- 从 `S01`、`S05` 读取基准偿付能力指标。
- 从 `KBQS_V` 读取账户、资产类型、认可价值和各风险暴露。
- 用 `S05` 中各类风险最低资本除以对应风险暴露，反推单位资本率。
- 加仓/减仓/建仓默认不把净新增资产计入实际资本；可在页面勾选“认可资产变化同步实际资本”。
- 上涨/下跌默认把估值变化计入实际资本，因为该模块模拟的是已有资产公允价值变化。

该工具用于内部管理测算和敏感性分析，不替代监管报送系统或完整偿二代复算引擎。
