# 偿付能力资产配置情景测算

本项目是一个本地 Streamlit 小程序，用于导入月度偿付能力 Excel 底稿，并估算资产配置变化对最低资本和偿付能力充足率的影响。

## 运行

```powershell
python -m streamlit run app.py
```

打开页面后，程序会自动读取当前 repo 根目录下唯一的 `.xlsx` 底稿。更换底稿时，只需要删除旧 Excel 并放入新的同结构 Excel，不需要修改源代码。

## 当前模块

- 加仓/减仓/建仓：按资产类型做比例或金额调整，金额单位为亿元。债券类资产可选择久期 bucket，利率风险抵减因子从 `MC_RESULT_资产端利率风险明细表` 动态反推，利差风险因子从 `CAL_DETAIL_最低资本明细表` 动态反推。
- 上涨/下跌：按资产类型做价格涨跌测算，估值变动默认计入实际资本和核心资本，并同步估算最低资本变化。
- 目标倒推：选择核心/综合偿付能力充足率目标值（100%、120%、150%）和单一资产类型，倒推出加仓/上涨或减仓/下跌所需的最小金额/比例；双向均不可达时显示无解。
- 政策参数：支持最低资本乘数、市场风险乘数、信用风险乘数，用于粗略模拟政策 overlay。

## 当前口径

- 从 `S01`、`S05` 读取基准偿付能力指标。
- 从 `KBQS_V` 读取资产类型、认可价值和各类风险暴露。
- 从 `MC_RESULT_资产端利率风险明细表` 按资产类型和久期 bucket 反推利率风险抵减因子：

```text
利率风险抵减因子 = 资产端利率风险MC / (账面价值净价 + 应收利息)
```

- 从 `CAL_DETAIL_最低资本明细表` 按资产类型反推利差风险因子：

```text
利差风险因子 = 利差风险MC / 利差风险暴露
```

- 市场风险、信用风险和量化风险按相关矩阵重算情景增量，再叠加到底稿基准值。
- 加仓/减仓/建仓默认不把净新增资产计入实际资本；可在页面勾选“认可资产变化同步实际资本”。
- 上涨/下跌默认把估值变化计入实际资本，因为该模块模拟的是已有资产公允价值变化。
- 目标倒推中的加仓结果固定同步认可资产变化到实际资本/核心资本；页面目标值会自动换算为相对当前基准的百分点变化。

更完整的计算逻辑见 [docs/calculation_logic.md](docs/calculation_logic.md)。

该工具用于内部管理测算和敏感性分析，不替代监管报送系统或完整偿二代复算引擎。
