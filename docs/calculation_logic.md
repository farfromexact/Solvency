# 偿付能力情景测算底层逻辑说明

本文说明当前小程序的测算口径。它是“基于现有月度底稿和规则参数的管理测算模型”，不是完整偿二代复算引擎，也不替代监管报送系统。

## 1. 数据来源

程序扫描 `origin stats/` 下的月度 Excel 底稿，按文件名中的报告月末和底稿时点/版本供页面选择。文件名约定为 `公司代码_报告月末_底稿时点[版本].xlsx`，例如 `1000_20260430_20260512.xlsx`。选定底稿后，关键 sheet 包括：

- `S01_偿付能力状况表`：读取认可资产、实际资本、核心资本、最低资本、核心/综合偿付能力充足率等基准指标。
- `S05_最低资本表`：读取寿险保险风险、非寿险保险风险、市场风险、信用风险及其子项最低资本。
- `KBQS_V_跨表取数视图`：读取账户、资产类型、认可价值和底稿资产暴露，用于展示基准资产结构和生成情景变化。
- `FLS05ACC_分账户最低资本表`：用于页面展示分账户最低资本，当前不直接参与重算。
- `MC_RESULT_资产端利率风险明细表`：用于按资产类型和久期 bucket 动态反推资产端利率风险抵减因子。
- `CAL_DETAIL_最低资本明细表`：保留风险 MC、风险暴露、是否计算标志及源行，用于动态反推风险因子与总表核对。先验证上层风险表头，避免只靠 MC 列后缀猜测风险含义。

总览按需读取 S01/S05，历史趋势仅读取各期 S01；进入明细页面才解析资产明细。缓存键包括路径、文件修改时间和解析版本。同名底稿替换后重新解析，并清空此前应用的情景。

KBQS 同时保留表层与穿透底层记录，不能直接加总解释为公司持仓。页面按层级分开展示，并保留来源文件、工作表、原始行号和原始利率风险暴露。当前版本未完成去重持仓重建，情景仍沿用原风险视图口径。核心必需数值缺失或无效时不补零。总表勾稽不通过时不生成情景结果。

月度归因比较的是所选两份底稿的 S01/S05 期末数，不默认把底稿期初当成上个月。充足率桥接先改变资本分子、再改变最低资本分母，两项合计等于充足率变化；风险子项未汇总分散效应，不能直接相加为总最低资本变化。

## 2. 情景输入

支持以下情景输入：

- 加减仓：模拟已有资产类型的配置变化。零持仓建仓暂不支持。保险公司可以通过加减杠杆实现资产规模变化，所以当前版本不强制要求同时录入资金来源或存量资产切换。
- 上涨/下跌：模拟已有资产估值变化。估值变化默认进入实际资本和核心资本，同时改变对应风险资本。
- 市场冲击：模拟股市整体涨跌，以及国债、地方政府债按久期 bucket 的收益率 bp 变化。固收价格变化按久期近似：

```text
加权修正久期 = Σ(逐笔修正久期 × 逐笔全价) / Σ逐笔全价
价格变化 = - 加权修正久期 × bp变化 / 10000 × 该久期 bucket 利率风险资产价值
```

如果要做“卖出 A、买入 B”的资产重新配置，可以录入两个情景叠加：A 减仓、B 加仓。

“等额资产切换”会生成这两行草稿，不直接改变已应用方案。修正久期缺失记录单列，并显示价值覆盖率；该桶覆盖不完整时不能做价格冲击，不以中点填补。以上价格公式为一阶近似，不包含凸性、非平行曲线冲击及负债端重估。

当前策略输入只保留资产类型维度；账户维度暂不作为测算入口。

编辑表中的启用行和明确勾选的市场冲击，在点击“计算并应用”后一起生效；未提交的编辑不改变正算结果。多条调整按列表顺序叠加，减仓/跌价超过剩余认可价值时拒绝应用。清空操作恢复基准与默认参数。

## 3. 目标倒推

目标倒推用于回答“为了达到所选核心/综合充足率，单一资产类型需要变化多少”。处理逻辑：

1. 用户输入目标充足率，选择“至少达到”或“调整到目标值”，并选择资产类型和债券久期。至少达到模式下，基准已高于目标则返回无需调整，不倒推出降至目标的方案。
2. 程序分别求解 `加仓/建仓` 和 `上涨/下跌` 两种动作，每种动作都会同时尝试正向变化和负向变化。
3. 正向搜索范围为 0 到该资产类型当前认可价值的 5 倍，负向搜索范围为 0 到把该资产类型减至 0；先分段扫描找可行区间，再二分求绝对值最小的满足目标金额。
4. 如果双向动作在搜索上限内都无法达到目标，显示“当前搜索范围内未找到可行方案”，金额保持空缺。搜索不包含融资、流动性、投资限额约束，也不宣称找到全局最优配置。

倒推与正算使用同一口径参数：配置变化默认不计入实际资本或核心资本，价格变化计入。倒推从底稿基准和已应用参数出发，不叠加已有资产调整。点击“用此方案替换当前情景”会整体替换生效列表，保留未四舍五入的金额以便正算复现。参数或底稿变化后旧方案不可应用。

市场、信用风险乘数仅作用于对应风险的情景增量，不改变原存量风险。最低资本乘数是总额情景参数，并非自动判断监管政策适用性。

## 4. 风险因子

### 4.1 App 默认：底稿校准口径

每期从 CAL_DETAIL 汇总同一资产类型的各风险 MC，除以该类型在原跨表风险视图中的认可价值，形成单位价值资本因子。零风险与未提供的风险字段区分处理：未适用区块的空白可不参与汇总，但“是否计算 = 是”或风险暴露非零时 MC 必须有效。每个风险合计必须与 S05 勾稽，各资产类型认可价值必须与 KBQS 一致；失败时拒绝生成校准口径情景，不自动退回旧因子。

覆盖利差、交易对手违约、权益、房地产、汇率、境外价格风险。境外明细是合并列，仅当 S05 境外固收或权益一项为零时，才可明确归入另一项；两者都非零时拒绝猜分。利率抵减继续使用 MC_RESULT 反推因子。

情景每类资产的风险增量 = 同类认可价值变化 × 相应单位价值资本因子。校准对各风险独立执行，避免因命中利率因子而漏掉同类资产的违约或汇率风险。这是固定底稿结构下的线性平均估算，不是逐笔监管 RF 或完整重估。当前只开放资产类型维度，不把全账户平均因子用于分账户测算。

App 默认启用校准口径；Python API 的 `PolicyParameters()` 保留旧默认以兼容既有调用，显式传 `use_calibrated_factors=True` 使用新版。零情景仍锚定 S01/S05。

### 4.2 旧简化口径（仅供兼容和对照）

关闭高级参数中的“使用底稿校准风险因子”时，情景按下列旧规则估算：

| 资产类别 | 当前简化因子 |
| --- | --- |
| 国债、地方政府债、政策性金融债、金融债、信用债等 | 利率风险抵减因子从 `MC_RESULT_资产端利率风险明细表` 动态反推 |
| 政策性金融债、金融债、信用债等 | 利差风险因子从 `CAL_DETAIL_最低资本明细表` 动态反推 |
| 债券型基金、固收类产品 | 权益价格风险 6.00% |
| 上市普通股票 | 权益价格风险 35.16% |
| 股票型/混合型基金、权益类/混合类资管产品 | 权益价格风险 25.87% |
| 未上市股权、长期股权投资 | 权益价格风险 41.00% |
| 股权投资基金 | 权益价格风险 45.10% |
| 债权投资计划 | 交易对手风险 9.30% |
| 固定收益类信托计划 | 交易对手风险 9.50% |
| 不动产、投资性房地产物权及相关产品 | 房地产风险 18.00% |

上表固定数值仅用于旧模式，不再是 App 默认口径，也不是经本程序验证的现行监管规则参数。

如果资产类型没有命中上述显式规则，但 `KBQS_V_跨表取数视图` 已有存量风险暴露，程序会启用底稿风险暴露兜底：按该资产类型的“风险暴露/认可价值”结构，乘以当前 `S05` 对应风险最低资本与全量风险暴露的比率，反推边际资本因子。该兜底用于避免有存量风险暴露的资产加仓后最低资本完全不变。

## 5. 利率风险处理

寿险利率风险按净现金流情景法理解：资产现金流是负债现金流的对冲项。因此买入国债、地方政府债、金融债、信用债等固收资产时，程序把对应利率因子作为“资产端利率风险抵减”，不是正向增加利率风险资本。

利率抵减因子从月度底稿反推：

```text
利率风险抵减因子
= 资产端利率风险MC / (账面价值净价 + 应收利息)
```

程序同时展示 `资产端利率风险MC / PV基础` 作为校验口径。债券类资产可选择久期 bucket：

```text
存量平均、<3年、3-5年、5-7年、7-10年、10-15年、15-30年、30年以上
```

如果选择“存量平均”，使用该资产类型全量存量的平均抵减因子；如果选择具体久期 bucket，使用该资产类型在该 bucket 内的平均抵减因子。该变化先作用于 `S05` 的“市场风险-利率风险最低资本”，且利率风险子项不低于 0。然后再进入市场风险相关矩阵。

## 6. 利差风险处理

债券类资产的利差风险因子从 `CAL_DETAIL_最低资本明细表` 反推：

```text
利差风险因子 = 利差风险MC / 利差风险暴露
```

因此政策性金融债、金融债、企业债、公司债、中期票据等不再使用固定利差因子。以当前底稿为例，政策性金融债利差风险因子约为 3.3716%，而不是旧模型里的 12.6016%。

## 7. 相关矩阵汇总

程序从 `S05` 读取基准子项资本，然后用简化相关矩阵重算情景增量：

1. 市场风险：利率、权益、房地产、境外固收、境外权益、汇率六个子项按偿二代相关矩阵汇总。
2. 信用风险：利差风险和交易对手违约风险按 0.25 相关系数汇总。
3. 量化风险：寿险保险风险、非寿险保险风险、市场风险、信用风险按偿二代量化风险相关矩阵汇总。

为保持与底稿基准口径一致，页面展示的基准指标仍以 `S01/S05` 为准；情景只把重算得到的增量叠加到底稿基准值上。

## 8. 实际资本

默认情况下：

- 加仓/减仓/建仓只改变认可资产和最低资本，不自动改变实际资本。
- 上涨/下跌改变认可资产，并同步改变实际资本和核心资本。

如果勾选“认可资产变化同步实际资本”，加仓/减仓带来的净认可资产变化也会计入实际资本和核心资本。

## 9. 当前局限

- 不重建完整 Excel 公式链。
- 不重算寿险负债现金流、完整利率曲线、损失吸收效应、控制风险最低资本和附加资本。
- 表层持仓仅取层级 0，层级缺失仍待核对；按账户和资产树追溯，但不能仅靠层级推断直接父节点，不按证券代码去重。不自动把父产品交易传导到底层，也不将表层持仓视图替换原风险视图情景基数。
- 大幅情景、复杂衍生品、境外资产和特殊政策折扣仍需要专门参数表和规则引擎。

当前版本适合做内部方向性测算和敏感性分析。更精确的下一步是把监管规则 PDF 中的因子、期限、评级、长期持有权益条件等整理成可维护参数表，并在利率风险模块接入资产/负债现金流久期重算。

## 10. 方案保存与比较

仅保存已应用的调整和口径，不保存未提交草稿或静态计算结果。同底稿最多保留 6 个命名方案，不覆盖同名条目；导出 JSON 包含格式版本、模型版本及文件名/时点/修改时间/解析版本标识。导入时严格检查字段、数值、减仓边界及底稿身份，再调用同一正算引擎重算；不反序列化代码或 pickle。

方案保存在当前浏览器会话，切换底稿会清空；点击“清空本次情景”及应用倒推方案不删除方案库。多方案比较的原始底稿基准不应用额外政策乘数，新旧因子对照仅改变因子开关。单资产敏感性各行从底稿独立出发，沿用当前参数，不叠加当前其他调整。等额切换不含交易费用、融资约束、税项和到账时差。
