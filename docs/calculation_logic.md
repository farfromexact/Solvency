# 偿付能力情景测算底层逻辑说明

本文说明当前小程序的偿付能力测算口径。它是“基于现有月度底稿反推的管理测算模型”，不是完整偿二代规则复算引擎，也不替代监管报送系统。

## 1. 数据来源

程序读取上传的月度 Excel 底稿，关键 sheet 包括：

- `S01_偿付能力状况表`：读取认可资产、认可负债、实际资本、核心资本、最低资本、核心/综合偿付能力充足率等基准指标。
- `S05_最低资本表`：读取各类风险最低资本，包括市场风险、信用风险及其子项。
- `KBQS_V_跨表取数视图`：读取资产明细视图中的账户、资产类型、认可价值和各风险暴露。
- `FLS05ACC_分账户最低资本表`：用于页面展示分账户最低资本，不直接参与当前情景重算。

当前模型依赖底稿中已经算好的结果值。也就是说，程序不重建完整 Excel 公式链，而是把现有底稿作为基准快照，再在基准快照上做敏感性测算。

## 2. 基准指标

基准指标来自 `S01`：

- 认可资产
- 实际资本
- 核心资本，等于核心一级资本加核心二级资本
- 最低资本
- 量化风险最低资本
- 核心偿付能力充足率 = 核心资本 / 最低资本
- 综合偿付能力充足率 = 实际资本 / 最低资本

页面展示的基准指标应与 Excel 底稿 `S01` 的期末数一致。

## 3. 单位资本率反推

当前模型采用“基准资本占用率法”。步骤如下：

1. 从 `KBQS_V` 汇总各风险暴露字段。
2. 从 `S05` 读取对应风险最低资本。
3. 用 `最低资本 / 风险暴露` 反推单位资本率。
4. 情景下重新汇总风险暴露，再乘以单位资本率，得到估算最低资本变化。

当前映射关系如下：

| 风险类型 | 风险暴露字段 | S05 资本项目 |
| --- | --- | --- |
| 利率风险 | 利率风险暴露 | 市场风险-利率风险最低资本 |
| 权益价格风险 | 权益价格风险暴露 | 市场风险-权益价格风险最低资本 |
| 房地产价格风险 | 房地产风险暴露 | 市场风险-房地产价格风险最低资本 |
| 汇率风险 | 汇率风险暴露 | 市场风险-汇率风险最低资本 |
| 利差风险 | 利差风险暴露 | 信用风险-利差风险最低资本 |
| 交易对手违约风险 | 交易对手风险暴露 | 信用风险-交易对手违约风险最低资本 |

这种方法保留了当前底稿的综合口径，但不会重新计算风险分散矩阵、损失吸收效应、穿透规则、久期曲线、评级迁移等细项。

## 4. 加仓/减仓/建仓模块

该模块用于模拟主动交易或配置调整，例如：

- 某类资产加仓 10%
- 某账户减仓 5%
- 对某资产类型新增 1 亿元配置

处理逻辑：

1. 用户选择维度：`资产类型` 或 `账户`。
2. 用户选择对象和变化方式：比例或金额。
3. 程序找到 `KBQS_V` 中匹配对象的所有资产行。
4. 按同一比例缩放这些行的认可价值和全部风险暴露字段。
5. 用新的风险暴露计算最低资本增量。

金额输入会先被转换为比例：

```text
变化比例 = 变化金额 / 当前认可价值
```

如果加仓和减仓的资金来源没有同时录入，认可资产会出现净变化。默认情况下，交易性加仓/减仓不直接改变实际资本；如果页面勾选“认可资产变化同步实际资本”，才会把净认可资产变化同步计入实际资本和核心资本。

## 5. 上涨/下跌模块

该模块用于模拟已有资产价格变动，例如：

- 股票上涨 10%
- 房地产资产下跌 5%
- 某账户资产整体上涨 3%

处理逻辑：

1. 用户选择维度：`资产类型` 或 `账户`。
2. 用户输入上涨/下跌比例或金额。
3. 程序按同一比例调整匹配资产的认可价值和风险暴露。
4. 估值变化默认计入实际资本和核心资本。
5. 调整后的风险暴露重新估算最低资本。

因此，上涨/下跌同时影响分子和分母：

```text
情景实际资本 = 基准实际资本 + 估值变化
情景核心资本 = 基准核心资本 + 估值变化
情景最低资本 = 基准最低资本 + 估算最低资本变化
```

## 6. 政策参数

页面保留了三个政策/口径参数：

- 最低资本乘数：例如 0.95 可粗略模拟最低资本按 95% 计算。
- 市场风险乘数：作用于市场风险相关增量。
- 信用风险乘数：作用于信用风险相关增量。

这些参数用于快速做 overlay 敏感性，不代表已经完整实现具体监管文件中的所有条件判断。

## 7. 输出指标

情景结果输出：

- 认可资产
- 实际资本
- 核心资本
- 最低资本
- 量化风险最低资本
- 核心偿付能力充足率
- 综合偿付能力充足率
- 风险暴露变化
- 各风险类型对最低资本变化的贡献

## 8. 当前局限

当前版本适合做方向性和敏感性测算，但需要注意：

- 不重算完整偿二代公式链。
- 不重算风险分散效应矩阵，只用基准单位资本率估算增量。
- 不自动识别资产买入资金来源；如果要模拟资产切换，需要同时录入买入项和卖出项。
- 不自动重算寿险负债、利率曲线、损失吸收效应、控制风险最低资本和附加资本。
- 对大幅度情景，线性单位资本率假设可能偏离真实监管计算结果。

后续如果要提高精度，应优先补充：风险分散效应重算、权益/REITs/长期持有风险因子参数表、资产切换资金来源建模、以及寿险负债和利率风险的专门测算模块。
